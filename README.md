## 💡 Sobre o Projeto

Este repositório reúne um portfólio prático de landing pages comerciais sob medida para empresas de serviços, comércio técnico e clínicas especializadas. 

Diferente de templates genéricos ou gerados massivamente por IA com fotografias falsas e animações lentas, cada projeto aqui foi desenhado e codificado do zero com:

1. **Rigor Técnico e Identidade Real:** Informações comerciais verificadas (endereços reais em São Paulo, mapas integrados, horários de funcionamento, credenciais profissionais como CRP, SATEPSI e alvarás).
2. **Widgets Interativos de Conversão (Zero Bloat):** Calculadoras dinâmicas de materiais, simuladores de demãos de tinta, montadores de listas elétricas e triagens clínicas confidenciais que formatam e enviam pedidos estruturados diretamente ao WhatsApp comercial do cliente.
3. **Performance Extrema:** Construídos com HTML5 semântico e CSS/JS nativo, sem bibliotecas externas pesadas desnecessárias (zero dependência de React/Next em páginas estáticas que precisam carregar instantaneamente em 4G).
4. **Acessibilidade e SEO Local:** Navegação por teclado, leitor de tela (ARIA e `<details>/<summary>` nativos), metadados OpenGraph completos e marcação estruturada JSON-LD (`MedicalBusiness`, `HomeGoodsStore`, `AutoRepair`).

## 🛠️ Stack Tecnológica & Princípios de Engenharia

```text
├── HTML5 Semântico      (Landmarks, main, header, nav, footer, details/summary)
├── CSS3 Moderno         (Custom Properties, Grid, Flexbox, Clamp typography, Mobile-First)
├── JavaScript ES6+      (Manipulação nativa do DOM, máscaras de input, serialização WhatsApp)
├── SEO & Dados Rich     (Schema.org JSON-LD, OpenGraph, Canonical, Twitter Cards)
└── Padrão Origamid      (Código limpo, acessível, sem dependências desnecessárias)
```

### Por que Vanilla JS & CSS Puro nestes projetos?
- **Tempo de carregamento < 0.5s** mesmo em conexões móveis limitadas (3G/4G).
- **Zero vulnerabilidades** de pacotes NPM depreciados.
- **100% de compatibilidade** com hospedagens estáticas (GitHub Pages, Netlify, Vercel, S3, Caddy).
- **Código legível e sustentável** a longo prazo sem necessidade de builds complexos.

## 💻 Como Rodar Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/Asilva-01/prospect-sites.git
   cd prospect-sites
   ```

2. Abra qualquer um dos sites diretamente no navegador ou utilize um servidor local leve:
   ```bash
   # Utilizando Python 3:
   python -m http.server 8000

   # Ou utilizando Node.js:
   npx serve .
   ```

3. Acesse no navegador:
   `http://localhost:8000/`
